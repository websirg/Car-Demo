# Websirg AutoHub — Multi-Brand Automotive Dealership & Workshop Portal

A modern, high-performance static website crafted for multi-brand automotive sales, certified pre-owned vehicles, bike showroom, doorstep test drives, and workshop service booking.

---

## 🚀 Key Features

- **Dynamic Vehicle Catalog:** Interactive car and bike showcases with budget, brand, body-type, and fuel-type filters.
- **Doorstep Test Drive Booking:** Interactive popup booking modal with time-slot selection and doorstep delivery.
- **Floating Action Buttons (FAB):** High-converting circular floating buttons with smooth floating waves, glowing radar pulses, and instant WhatsApp/Call connectivity.
- **Instant Financial Calculator:** Integrated EMI calculator for down payment and tenure planning.
- **Service & Workshop Booking:** Periodic service packages, major repair estimations, and appointment scheduling.
- **Fully Responsive & SEO Ready:** Optimized for mobile, tablet, and desktop viewports with zero layout shifts.

## 💻 Getting Started

Simply open `index.html` in any modern web browser or serve locally with any static HTTP server:

```bash
# Using Python 3
python3 -m http.server 3000

# Using Node.js npx
npx serve .
```

Then visit [http://localhost:3000](http://localhost:3000).
